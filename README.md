# Stone Matrix｜飛行石矩陣 3D

## [直接試玩 ↗](https://rolanthhuang.github.io/stonematrix/)

在立體石室裡點選底面與兩側牆面，讓光柱穿透停在半空中的飛行石。每條光柱依命中的石頭數分別計算返還點數。

遊戲以 **4 × 4 × 4 三維格點**計算。石塊帶有凹凸岩面、缺角、緩慢懸浮與投影；命中時裂紋會發光。每局有 14 顆飛行石，底面及兩側牆面各有 16 個可選投注格，共 48 條光柱。

可拖曳旋轉整個石陣、滾輪或雙指縮放，從不同方向查看飛行石與光柱。外圍遺跡以低對比與霧感呈現，保持主要投注區清楚。

### 操作方式

1. 直接點石室底面、左牆或右牆的格子，也可使用旁邊的投注盤。
2. 再點同一格即可取消；每格只會選取一次。
3. 在「每格投注金額」選擇 1、5、10、25 或 100 點。總投注＝選取格數 × 每格金額。
4. 按「啟動石陣」，等待飛行石移動、停下，再觀看光柱穿透。
5. 在結果清單查看每條光柱的命中數與返還倍數。選取較多光柱時可展開完整清單。

### 視角與重新開始

- 拖曳石室空間旋轉；滾輪或雙指手勢縮放。拖曳不會放置投注。
- 「左轉／右轉」每次調整 30 度；「視角歸位」回到初始鏡頭，保留點數與投注。
- 「重新開始」隨時可用：取消正在運行的當局、恢復 10,000 點、清空投注與結果，並回到初始視角。

底面光柱向上穿透，兩側牆面的光柱橫向穿透。同一顆石頭可被不同方向的光柱分別命中；每條光柱各自結算。

### 示範獎表

| 單條光柱命中石頭數 | 單格返還倍數 |
| --- | --- |
| 0 | 0× |
| 1 | 1× |
| 2 | 2× |
| 3 | 3× |
| 4 | 16× |

返還點數＝各格投注金額 × 對應倍數的總和；淨值＝返還點數 − 總投注。1× 代表返還該格投入的點數。

每局會從 64 個格點中重新隨機選出 14 個不重複位置。預覽石陣和上局石陣不代表下局結果。

此版本使用模擬點數，初始為 10,000 點。獎表與石頭生成規則是試玩用設定，尚未定稿。

### 開啟與部署

- 直接開啟上方試玩連結，或下載 `index.html` 後以現代瀏覽器開啟。
- 單一 HTML 已包含畫面、程式與樣式，可離線使用，無須安裝套件或設定 API。
- 遊戲會在可用時將點數與選取狀態保存在目前瀏覽器；清除網站資料會回到預設狀態。
- 支援桌面與手機排版，並配合系統的深淺色及減少動畫偏好。
- GitHub Pages 使用 `main` 分支根目錄，`.nojekyll` 保留為靜態網頁部署。

### 修改與打包

`src/game.html` 保存介面與遊戲規則；`src/stone-renderer.js` 保存立體場景、岩石材質、光影、旋轉與點選。

```sh
npm ci --ignore-scripts
npm run build
```

打包會將 Three.js 與遊戲一起內嵌到 `index.html`。執行遊戲時不需要 CDN、套件伺服器或 API。Three.js 的授權文字保留於 `THREE-LICENSE.txt`。
